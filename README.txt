# Smart Movie Recommendation System

## Run locally

1. Open a terminal in this folder.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Start the app:
   `streamlit run app.py`
4. Open the localhost address shown by Streamlit, usually:
   `http://localhost:8501`

## CO Mapping
- CO1: Item-based Collaborative Filtering + Matrix Factorization (SVD)
- CO2: TF-IDF + Cosine Similarity
- CO3: Weighted Hybrid recommendation
- CO4: User/Movie Embeddings + Neural Collaborative Filtering
